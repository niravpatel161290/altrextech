## 🏢 About Altrex Technologies

**Altrex Technologies** is an industrial intelligence and digital transformation company headquartered in **Ahmedabad, India**. We specialize in building and deploying advanced **Industrial IoT**, **Web SCADA**, **GIS**, **Fleet Management**, **Energy Management**, and **Enterprise Analytics** platforms that transform the way industrial organizations monitor, manage, and optimize their operations.

> *"We don't just connect machines — we connect industries to their future."*

Altrex bridges the gap between **Operational Technology (OT)** and **Information Technology (IT)**, enabling organizations across energy, utilities, manufacturing, smart cities, and infrastructure to achieve real-time visibility, data-driven decision-making, and long-term operational excellence.

## 🏗️ Technology Stack (This Platform)

This repository contains the **Altrex Technologies web platform**, built with a modern, high-performance stack:

```
Frontend         React 18 + TypeScript + Vite
UI Components    Shadcn/UI + Radix UI
Animations       Framer Motion
Styling          Tailwind CSS + Custom Design Tokens
Icons            Lucide React + React Icons
Routing          React Router v6
Build            Vite + ESBuild
Deployment       Vercel
```

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
